## Accepted boundary

ADR-0050 records the approved Wave 2 constraints before behavior moves:

- one production Node dependency boundary in `server/package.json`;
- separate API, realtime, and worker entrypoints, with CPU-heavy work kept off the API event loop;
- private S3-compatible retained-audio storage in production and filesystem storage only in
  development/test;
- one monotonic parent deadline propagated with `AbortSignal`, bounded per-process token buckets,
  and Postgres-backed durable credential/replay state;
- no Redis or NATS in the lean target;
- the ADR-0038 controlled-device identity model, including server-derived tenant/role authority and
  hash-only stored device secrets while general-user login remains owner-gated off.

The same boundary is reflected in `docs/architecture/10-10-platform.md` and its focused proof is
documented in `docs/TESTING.md`.
