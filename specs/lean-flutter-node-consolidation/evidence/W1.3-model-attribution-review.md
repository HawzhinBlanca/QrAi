# W1.3 component attribution review

Date: 2026-08-06<br>
Scope: W1.3 prerequisite contract for QA-6; database round-trip remains W1.8.

## Result

Inference identity is now producer-authored and component-level. The closed vocabulary is ASR,
forced aligner, Quran aligner, acoustic scorer, and calibrator. An active component must carry its
implementation id, exact lowercase SHA-256 artifact digest, dataset version, analysis basis, and
calibrator linkage. An unavailable component gives a reason and makes no artifact claim.

The old request authority was removed from Flutter, session creation, alignment persistence, and
both public ML proxy implementations. A session selects the sole configured alignment model on the
server; later alignment writes inherit that session identity. The compatibility `modelVersion`
field is derived from the producer's primary component and cannot be supplied by a caller.

## Artifact truth

- Quran aligner: SHA-256 of the exact `services/ml-inference/alignment.js` bytes plus canonical
  provenance-v2 dataset identity.
- OpenAI Whisper: digest extracted from the package's verified checkpoint URL.
- Hugging Face ASR: refuses service when `ASR_MODEL_DIGEST` is absent.
- Forced aligner: refuses successful attribution when `FORCE_ALIGN_MODEL_DIGEST` is absent.
- Acoustic scorer: SHA-256 of its exact producing source; deterministic heuristic dataset label.
- Calibrator: explicitly unavailable until an approved calibration artifact exists.

No model or evaluation metrics were invented, and no canonical Quran bytes were changed.

## Automated proof

- TypeScript contract tests: closed vocabulary, all five records, unknown component, mismatched
  expected digest, malformed digest, duplicate, compatibility-label mismatch, unavailable artifact.
- Node runtime/producer tests: exact source digest, composed upstream attribution, caller-model
  rejection, response/audit binding, strict OpenAPI producer validation.
- Python tests: Whisper URL digest, missing external aliases, expected-digest mismatch, forced
  aligner refusal, acoustic scorer and unavailable calibrator.
- Rust compile, clippy, unit tests, and Node/Rust database parity: producer identity accepted only
  when valid; missing/unknown/malformed/contradictory attribution becomes a generic 502.
