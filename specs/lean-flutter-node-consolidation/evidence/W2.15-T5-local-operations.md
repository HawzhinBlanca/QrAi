## Implemented proof

- `createJobStore().requeueDead` accepts only an in-tenant `admin` or `ops` actor, locks an
  immutable dead source, validates its stored document, and creates one audited successor using a
  deterministic replay key. It never resets attempts or lease generations. Repeating the replay
  returns the same successor and leaves exactly one replay audit.
- `server/scripts/requeue-dead-job.mjs` requires the restricted runtime role and prints only source
  and successor identifiers plus state. It has no public HTTP route and never prints payloads or
  raw errors.
- `tests/security/job-boundary.test.mjs` proves recursive sensitive-field refusal, byte/string/
  array/field/depth bounds, fixed persisted error codes, finite metrics, absence of an online
  `eval_runs` writer, and absence of signing-key authority from the job runtime.
- Architecture, ADR, testing, data inventory, staging recovery, and threat-model documents now
  describe the implemented at-least-once/exact-database-effect boundary, privacy crash recovery,
  worker operations, dead-letter replay, retention gap, and residual risks.
