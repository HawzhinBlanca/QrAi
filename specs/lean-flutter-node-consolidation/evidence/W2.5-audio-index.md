# W2.5 evidence — local Node audio chunk indexing

**Status:** complete; local, image, and exact-candidate remote proof are green<br>
**Date:** 2026-08-08

## Scope

- Added `server/src/routes/recitation.mjs::indexAudioChunk` and registered
  `POST /v1/audio-chunks` as the 38th local/portable Node route.
- Added `validateRealtimeTicket`, returning claims only after exact field/version/session/unsigned-u64
  expiry/boolean/HMAC validation; preserved the existing wire minter and boolean verifier.
- Derived tenant/session/learner/retention only from signed claims and required current tenant-scoped
  session/consent state to agree before insertion.
- Preserved usable-span validation, default sample rate, session audit lineage, exact response shape,
  and idempotent retry behavior.
- Forced the parity harness to port the route explicitly so “shell” cannot silently proxy Rust.
