# W2.15 T4 evidence — same-package durable worker

Date: 2026-08-07

## Implemented

- Added `server/src/worker.mjs` as a second command in the existing Node package and production
  Dockerfile. Compose adds an internal-only worker service with no published host port and the same
  restricted runtime database URL and audio storage boundary as the API.
- Added strict whole-number configuration for poll interval, operation timeout, lease, retry bounds,
  bind address, and shutdown grace. Startup refuses a missing database/ML key, an unguarded metrics
  endpoint, a privileged DB role, or a lease that does not exceed its operation deadline.
- Added deterministic global institution discovery with a fixed 10,000-tenant ceiling. The global
  registry read installs no tenant GUC; every claim, state summary, and effect remains a separate
  forced-RLS `withTenant` transaction.
- Polling rotates the first tenant each round and claims at most one job per tenant per pass. Metrics
  expose only closed job kind/outcome/state vocabularies and aggregate counts—never tenant, learner,
  session, job, trace, or object-key labels.
- SIGINT/SIGTERM stop new polls, abort/drain active work, close the private probe server, storage,
  and Postgres exactly once, with a referenced hard deadline and fixed non-sensitive log messages.

## Focused proof

- Worker lifecycle/config/metrics/signal suite: 4/4 passed, including a real child process against
  an ephemeral migrated database and provisioned restricted role. `/ready` and `/metrics` served,
  SIGTERM exited code 0 inside the grace period, and stderr contained no topology or subject IDs.
- Image/topology/invocation/Compose group: 28/28 passed.
- Live DB tenant/role group: worker discovery was deterministic and left no pooled tenant GUC.
- Server production build passed with the worker included in the package lint boundary.
