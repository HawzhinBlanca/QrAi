# W2.12 evidence — shared dependency deadlines and cancellation

**Date:** 2026-08-07<br>
**Scope:** approved W2.12<br>
**Criterion:** BE-4

## Implemented

- One dependency-free, monotonic deadline primitive now composes caller disconnects and timeout
  signals and covers both response headers and response-body consumption.
- The API allocates one request budget before local work and propagates it through the Rust
  compatibility proxy, ML/ASR, finalization, privacy, review-audio storage, agent workers, and
  request-scoped Postgres transactions.
- Postgres enforces connection and server-side statement/idle-transaction timeouts. A timed-out
  write is cancelled by Postgres and rolled back; the application never races an unresolved
  transaction promise or claims completion.
- ML and agent processes validate timeout configuration strictly, reuse one deadline across their
  dependency fan-out, abort hung calls, and return fixed retryable errors without leaking upstream
  details.
- Review-audio audit state distinguishes an attempted delivery from a fully served response, so a
  partial or hung object read cannot be recorded as completed playback.

## Focused proof

- Hermetic fault suite without a database: **5 passed, 2 explicitly skipped** because live
  Postgres was unavailable to that invocation.
- Live fault suite with the restricted database: **7/7 passed** with no skips. It proved:
  - a response body that hangs after headers is aborted and its socket is closed;
  - strict invalid-timeout boot refusal;
  - a hung Rust compatibility dependency returns a fixed bounded error and is disconnected;
  - the real ML child aborts a partial ASR response and writes no completion audit;
  - the real agent child aborts a partial platform response;
  - Postgres cancels and rolls back a write followed by `pg_sleep`, while an API advisory-lock
    wait returns retryable `503` and commits no progress;
  - privacy and review-audio storage hangs leave durable state unchanged and never claim deletion
    or playback completion.
- Affected API/database/audio/privacy/finalization integration groups passed with no failures.
- Direct API parity: **387/387 passed**.
- Every executable route through the Node port: **331/331 passed**.
- Server package lint/typecheck/build and `git diff --check`: passed.
