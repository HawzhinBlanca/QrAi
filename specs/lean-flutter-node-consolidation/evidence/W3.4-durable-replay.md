## Implemented boundary

- Migration 0036 adds one forced-RLS `realtime_ticket_replay_claims` table with composite
  tenant/session/nonce-hash uniqueness, structural tenant/session ownership, cascade deletion,
  lowercase SHA-256 and full u64 expiry constraints, and a deterministic expiry index. Raw tickets
  and nonces are never stored.
- `server/src/realtime/replay.mjs` accepts validated claims only. It hashes the exact signed nonce
  bytes without normalization and claims through the existing restricted `db.withTenant` boundary
  using one atomic `INSERT … SELECT … ON CONFLICT DO NOTHING RETURNING` transaction. Database time
  independently rejects expired or unknown/mismatched claims.
- Admission performs replay after Origin, ticket, and rate validation but before WebSocket upgrade.
  Fresh claims alone increment `accepted`; consumed or invalid scope is a bodyless generic 401, and
  database error/timeout is a bodyless 503 with no memory fallback. The admitted socket context no
  longer contains the nonce.
- Cleanup deletes at most 1,000 database-expired rows per ordered `FOR UPDATE SKIP LOCKED` pass. One
  unref'd interval suppresses overlap, retains rows on failure, and is drained before the database
  pool closes. Replay and cleanup metrics contain only closed outcomes and counts.
- No Redis/NATS/broker dependency, package, lockfile, service, port, public route, client, audio
  handler, Compose edge, or Rust source changed. Rust remains the only public realtime traffic target
  and compatibility oracle.
