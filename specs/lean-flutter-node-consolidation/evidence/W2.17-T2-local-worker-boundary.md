## Implemented boundary

- `job-worker` owns the injected local inference runtime and composes the durable workflow handlers.
- The Node API enqueues and polls durable work; it does not claim, execute, retry, or complete jobs.
- Session finalization and Tajweed evaluation use local runtime methods inside the worker, with the
  parent cancellation signal and bounded operation deadlines.
- Durable, sanitized API-domain errors are restored to callers without persisting internal URLs,
  raw dependency errors, audio, or secrets.
- Direct and through-Node parity/E2E harnesses run explicit subject-scoped workers; no test restores
  inline API execution.
