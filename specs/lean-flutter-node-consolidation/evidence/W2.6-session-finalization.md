# W2.6 evidence — local Node session finalization

**Status:** complete; local, image, and exact-candidate remote proof are green<br>
**Date:** 2026-08-08

## Scope

- Added local `POST /v1/recitation-sessions/{id}/finalize` as the 39th Node route.
- Reused one destructive alignment transaction for both client-reported practice writes and
  server-derived finalization; there is no second alignment writer.
- Released the database connection before transcript/alignment network calls and bounded both
  calls by one monotonic request deadline.
- Required exact, model-matching producer provenance before storing server-derived evidence.
- Made alignment replacement atomic: one invalid claimed row rolls back the whole replacement and
  preserves prior practice evidence.
- Preserved consent refusal, lost-chunk accounting, retry idempotence, tenant isolation, generic
  upstream errors, trace handling, and immutable canonical Quran bytes.
- Forced the new finalizer parity suite through both the Rust oracle and the Node routing shell in
  the canonical gate.
