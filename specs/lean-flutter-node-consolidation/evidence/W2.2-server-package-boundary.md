# W2.2 evidence — server package boundary

**Status:** engineering proof complete; ledger remains open pending required remote CI<br>
**Date:** 2026-08-07

## Implemented seam

- `server` is a pnpm workspace package named `@quran-ai/server`, ESM-only on Node 22.13 or newer.
- Its production dependency boundary declares Fastify, CORS, JOSE, `postgres`, and `pg`; TypeScript
  and Node types are development-only package tooling.
- `server/src/app.mjs::createApplication` is side-effect free and delegates to the unchanged
  `services/node-api/server.mjs::buildServer` strangler implementation.
- Importing the package does not bind a socket. Construction, readiness, injection, and close are
  independently testable.
- Root and canonical type/build workflows include the server package, and canonical verification
  invokes the standalone lifecycle test exactly once.
- Root development copies of runtime libraries remain temporarily because legacy source files and
  root tests still resolve them. W2.4 removes them incrementally as those modules move; this task
  does not pretend that relocation has happened.

No route behavior moved, traffic remains on Rust, and no standalone production-image claim is made.
