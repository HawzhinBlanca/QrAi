# W2.4 slice 1 evidence — relocate the insecure-configuration leaf

**Status:** engineering proof complete; W2.4 remains open for the remaining modules and remote CI<br>
**Date:** 2026-08-07

## Scope

- Moved `services/node-api/lib/insecure.mjs` to `server/src/lib/insecure.mjs`.
- Updated the runtime importer in `services/node-api/server.mjs` and the direct contract importer in
  `tests/node-api/boot-guard.test.mjs`.
- Kept every existing export, including `LEGACY_VAR`; no security decision or accepted environment
  value changed.
- Removed the old path rather than leaving a compatibility duplicate. The Rust-backed proxy
  rollback entrypoint remains unchanged.

This is deliberately one dependency-free leaf. It does not claim that W2.4 or the Node migration is
complete.

## Red-first and focused proof

The new relocation guard initially failed all three assertions: the legacy path still existed, both
callers still imported it, and the canonical gate did not invoke the guard. After the mechanical
move, the first green attempt caught an omitted existing export (`LEGACY_VAR`) in the test's public
surface inventory. The inventory was corrected to preserve that export rather than deleting it.

```text
node --test tests/node-api/module-relocation.test.mjs \
  tests/node-api/boot-guard.test.mjs \
  tests/node-api/shell.test.mjs \
  tests/node-api/production-image.test.mjs

# fail 0

pnpm --filter @quran-ai/server build
# exit 0

```


The temporary container was removed. This local image id is engineering evidence only, not a
release digest.
