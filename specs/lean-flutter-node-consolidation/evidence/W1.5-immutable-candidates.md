# W1.5 evidence — immutable candidates; benchmark still blocked

**Status:** engineering prework proven; W1.5 remains open because no eligible benchmark exists<br>
**Date:** 2026-08-06

## What is now enforced

- The checked-in registry contains exactly identified OpenAI Whisper `base` and Tarteel Quran-ASR
  artifacts. Its selection is `blocked-no-eligible-benchmark`; `selectedCandidateId` is null.
- The registry rejects a `reviewed-winner` label unless the named candidate exists, has an approved
  license review, is runnable, is benchmark-eligible, and carries an evidence digest.
- A runtime must name a registered candidate and match its runtime, model id, immutable revision,
  and artifact digest before allocating a model.
- Hugging Face revisions must be full commit hashes. The primary downloaded weight file is hashed
  before pipeline load; mutable aliases and mismatches fail.
- Benchmark input must bind candidate/runtime-lock/image/dataset/evaluator/source identities,
  approved protocol roles, complete accent/age/device/noise slices, metrics, and resource measures.
- Declared fixtures can test the validator but always return `eligibleForReview: false`.

## Why the task is not checked

There is no approved, consented, sealed Kurdish-L1 held-out corpus and no tracked audio. The draft
protocol still requires product-owner, Quran-scholar, privacy/legal, data-steward, minor-consent,
and license approval. Public IqraEval data is Arabic-L1 adult/elicited and cannot satisfy the
required Kurdish, child, natural-error, device, and noise slices. No candidate was benchmarked or
selected, no metric was invented, and the current generic `base` image remains a placeholder.
