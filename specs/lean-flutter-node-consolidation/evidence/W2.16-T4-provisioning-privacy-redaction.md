## Implemented boundary

- Added one restricted-role operator command, not an API. It accepts tenant/admin/target identifiers
  plus an optional complete new-user description; raw invitation or session-role arguments are
  unknown and rejected.
- The command validates a stored same-tenant `admin`, invites an existing user without changing or
  accepting their role, and creates a missing user only as learner, teacher, or scholar.
- The command generates a 256-bit invitation internally, writes only its SHA-256 hash, records the
  admin actor in the audit event, uses one fixed 24-hour lifetime, and emits the raw invitation once
  on successful stdout. Its failure output is fixed and never echoes arguments or database errors.
- Privacy export inventories device identity using only bounded aggregate count markers. It returns
  no raw credentials, hashes, session identifiers, invitation identifiers, or audit metadata.
- Privacy deletion removes every tenant/user device session generation and invitation before any
  later user-erasure step while preserving the existing durable privacy transaction and ordering.
- Added the command to the server package lint/build boundary and updated the exact package contract.
