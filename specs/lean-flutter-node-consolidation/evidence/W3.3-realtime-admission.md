## Implemented boundary

- One pure `server/src/realtime/admission.mjs` authority reuses the existing `rt_v2` validator and
  bounded token bucket. It verifies exact HMAC/session/tenant/non-empty-retention/expiry semantics,
  observes time once, and refuses more than 3,600 seconds of remaining ticket lifetime.
- Browser Origin matching is exact. Missing Origin remains refused unless the native policy is
  explicitly enabled, and that switch never accepts a supplied disallowed Origin.
- The default peer bucket is 200 burst with one-token-per-50-ms refill. Forwarded headers are
  ignored unless bounded trusted hops are explicitly enabled. Refusals are empty generic
  401/403/429 classes with a bounded `Retry-After`.
- Exact `@fastify/websocket` 11.3.0 is the only direct server adapter. Only the exact session-audio
  route upgrades; an accepted shadow receives 101 and immediately closes 1013/unavailable without
  reading, storing, forwarding, indexing, or acknowledging audio.
- The socket seam receives frozen verified claims and nullable trace, never the raw credential.
  Private metrics expose only accepted/origin/ticket/rate outcomes with no identity or URL labels.
- Compose keeps `node-realtime` internal, unpublished, and unrouted from Web/gateway traffic. The
  Rust gateway remains the production traffic target and executes the same named hostile corpus.
