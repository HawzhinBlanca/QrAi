# W2.15 T2 evidence — tenant-scoped durable job runtime

Date: 2026-08-07

## Implemented

- Added one package-owned job store with tenant-scoped enqueue, idempotency conflict detection,
  concurrent `FOR UPDATE SKIP LOCKED` claims, monotonic attempts/lease generations, bounded retry,
  dead-letter transition, fenced completion, fixed error codes, and status summaries.
- Added one bounded runtime with per-operation deadlines, deterministic capped exponential backoff,
  closed low-cardinality metrics, active-attempt drain, and atomic domain-effect/job completion.
- Restricted payloads and results to bounded JSON documents and rejected raw audio, transcripts,
  credentials, secrets, tokens, URLs, non-JSON values, and unbounded structures.
- Closed the stale-worker race: when a newer worker owns the lease, the old runtime records a
  `stale` outcome and cannot run the commit callback or alter the authoritative retry/dead state.
- Added the job sources to the server production lint boundary and registered their live test
  exactly once in canonical verification.
