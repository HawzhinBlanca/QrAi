## Implemented boundary

- Added one `identity/device-sessions.mjs` authority for 256-bit, domain-prefixed access, refresh,
  and invitation credentials. Postgres receives only SHA-256 hashes; raw values exist only at
  issuance.
- Pinned access life to 15 minutes, idle family life to 7 days, and absolute family life to 30
  days. Rolling idle expiry uses `GREATEST`, so concurrent access cannot shorten a session.
- Made invitation consumption, access resolution, refresh rotation, replay-family revocation, and
  logout use the restricted tenant-discovery boundary; the runtime contains no raw database/GUC
  escape hatch.
- Made refresh replay commit whole-family revocation and its audit record before the generic 401 is
  raised. Concurrent refresh has one winner and one durable replay response.
- Reserved only the `qrai_at_v1.` Bearer namespace for database-backed device access. Other Bearer
  credentials, the pilot cookie, and explicitly enabled development headers preserve their prior
  order and behavior.
- Joined the current same-tenant `users` row for every access, so a credential never freezes or
  supplies its own authorization role.
- Extracted the shared API error classes without breaking the existing `authz.mjs` export surface.
- Added exact architecture and canonical-invocation guards and extended server lint to the new
  identity module.
